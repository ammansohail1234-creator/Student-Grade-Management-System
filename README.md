Student Grade Management System

A beginner-friendly Python application designed to manage student records, calculate academic grades, and display class statistics.

Project Overview

The Student Grade Management System is a modular Python project that allows users to add student information, enter marks, calculate average scores, assign grades automatically, and view student records.

Student data is stored locally in a JSON file for persistence.

Features

* Add new student records
* Enter marks for three subjects
* Calculate average marks automatically
* Assign grades based on performance
* View all saved student records
* Display class statistics
* Store records using JSON

Technologies Used

* Python 3
* JSON
* Python modules and functions

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the VS Code terminal.
5. Run:

python main.py
